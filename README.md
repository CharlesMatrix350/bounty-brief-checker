# Bounty Brief Checker

Bounty rules are spread across a page, a social post and a blog, and these sources often disagree. Bounty Brief Checker uses four agents to read all of them, find the conflicts, and write one brief where every fact shows its source and every open conflict is marked.

Built for the Open Agent Hackathon 2026, Track: The Agent That Can Explain Why.
